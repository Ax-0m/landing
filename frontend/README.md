# Crowned — fan landing page
Run: `cd frontend && yarn install && yarn start` (frontend only, no backend needed).
Copy and sample data: `frontend/src/content.js` holds every word, link and number.
Design tokens: `frontend/src/styles.css` (CSS variables at the top of the file).
Logos: `frontend/public/crown.png` and `frontend/public/wordmark.png`; page title, meta description and Open Graph tags: `frontend/public/index.html`.
